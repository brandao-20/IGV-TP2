SIG-AL — TP2 Informação Geográfica e Visualização
Opção 2: Análise Alfanumérica e Espacial de Dados

1) Pré-requisitos
- Docker Desktop ativo
- Node.js 18 ou superior
- Chrome
- Ficheiros do docente:
  BGRI2021_1609.zip
  Continente_CAOP2025_parcial.zip
  Estabelecimentos_de_Alojamento_Local.zip
  dem_srtm_pt_25m.zip

2) Preparar dados
Criar/usar a pasta data na raiz do projeto e descompactar os ZIPs para lá.
Estrutura final esperada:

data/Continente_CAOP2025_parcial.gpkg
data/BGRI2021_1609/BGRI2021_1609.gpkg
data/BGRI2021_1609/C2021_FSINTESE_VARIAVEIS.csv
data/Estabelecimentos_de_Alojamento_Local/Estabelecimentos_de_Alojamento_Local.shp
data/Estabelecimentos_de_Alojamento_Local/Estabelecimentos_de_Alojamento_Local.dbf
data/Estabelecimentos_de_Alojamento_Local/Estabelecimentos_de_Alojamento_Local.shx
data/Estabelecimentos_de_Alojamento_Local/Estabelecimentos_de_Alojamento_Local.prj
data/dem_srtm_pt_25m.tif

3) Arrancar infraestrutura
Na raiz do projeto:

docker compose up -d

Serviços:
- PostGIS: localhost:5432
- pgAdmin: http://localhost:5050
  email: admin@pgadmin.org
  password: admin
- GeoServer: http://localhost:8080/geoserver
  user: admin
  password: geoserver

4) Criar base de dados e importar dados
Windows PowerShell:

powershell -ExecutionPolicy Bypass -File .\sql\02_import_commands_windows.ps1

Linux/macOS:

bash ./sql/02_import_commands_linux_macos.sh

5) Instalar dependências Node.js

copy .env.example .env       [Windows]
cp .env.example .env         [Linux/macOS]
npm install

6) Publicar automaticamente as camadas no GeoServer

npm run publish:geoserver

Camadas publicadas:
- igv:geo_vc_municipio
- igv:geo_vc_freguesias
- igv:geo_vc_alojamento_local
- igv:geo_vc_alojamentos_por_freguesia
- igv:bgri2021
- igv:dem_srtm_25m, se o GeoTIFF existir em data/dem_srtm_pt_25m.tif

7) Correr aplicação

npm start

Abrir:
http://localhost:3000

8) Testes rápidos
- Abrir http://localhost:3000/api/health
- Confirmar que aparece ok:true
- Abrir o GeoServer > Layer Preview e testar as camadas igv:...
- No mapa, ligar/desligar layers
- Selecionar uma freguesia e clicar em Analisar freguesia
- Desenhar uma área e clicar em Executar análise da área
- Clicar no mapa, definir raio e pesquisar alojamentos

9) Para a entrega final
Não incluir node_modules.
Incluir apenas:
- código-fonte do geoportal
- apresentação PPTX/PDF
- vídeo demonstrativo

Nome final do ZIP: IGV_DDDDD.zip
